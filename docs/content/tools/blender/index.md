### Installation

- Recommended version with Cook: *5.1*
- Windows binary: [https://download.blender.org/release/Blender5.1/blender-5.1.2-windows-x64.msi](https://download.blender.org/release/Blender5.1/blender-5.1.2-windows-x64.msi)

### Configuration

Example configuration for Blender in the `tools.json` configuration file:

```json
"Blender": {
    "executable": "C:\\Program Files\\Blender Foundation\\Blender 5.1\\blender.exe",
    "version": "5.1.2",
    "maxInstances": 1,
    "timeout": 600
}
```
